# Netflix EDA & Dashboard — Power BI

## Project Overview
Project ini merupakan Exploratory Data Analysis (EDA) terhadap Netflix Titles Dataset menggunakan Power BI.
Project mencakup proses eksplorasi data, visualisasi, dan pembuatan dashboard untuk memahami karakteristik konten Netflix.

## Objectives
- Menganalisis distribusi Movie dan TV Show
- Mengidentifikasi negara dengan jumlah konten terbanyak
- Menganalisis distribusi rating
- Mengeksplorasi genre konten
- Menganalisis tren konten berdasarkan tahun
- Menganalisis durasi film dan jumlah season TV Show

## Key Analysis
- Content Distribution
- Content Release Trend
- Top Genres
- Content by Rating
- Movie Duration Distribution
- TV Show Season Distribution

## Tools
- Power BI
- Power Query

## Dataset
Netflix Titles Dataset

## Dashboard
Dashboard menggunakan tema dark dengan aksen merah yang terinspirasi dari visual Netflix.
